======================================================================
        ESTATE VERSE - COMMERCIAL REAL ESTATE PLATFORM
                    Setup & Installation Guide
======================================================================

PROJECT OVERVIEW:
EstateVerse is a modern commercial real estate website built with Vite,
React, TypeScript, and custom CSS. The platform helps users discover
premium office spaces, retail locations, warehouses, and industrial
properties.

======================================================================
TECHNOLOGY STACK:
======================================================================

Frontend:
  - Vite 7.3.1 (Build tool & Dev server)
  - React 18+ with TypeScript
  - Custom CSS (Pure CSS, no Tailwind)
  - React Router DOM (Navigation & Routing)
  - Axios (HTTP Client for API calls)

Backend (Planned):
  - Java Spring Boot
  - Running on localhost:8080

Design:
  - Responsive Design (Mobile, Tablet, Desktop)
  - Dark theme for header/footer
  - Light theme for main sections
  - Modular component architecture

INSTALLATION:
======================================================================

1. Clone the repository:
   git clone <your-github-repo-url>
   cd EstateVerse

2. Install dependencies:
   npm install

3. Start development server:
   npm run dev
   
   The app will run on: http://localhost:5173 (or next available port)

4. Build for production:
   npm run build

5. Preview production build:
   npm run preview

======================================================================
CSS ARCHITECTURE:
======================================================================

Each component has its own CSS file:
- Button.css             - Button styles (primary, secondary, outline)
- Logo.css              - Brand logo styling
- Header.css            - Header/navigation bar styles
- Navigation.css        - Navigation menu links
- MobileMenuToggle.css  - Hamburger menu icon
- VerticalNavbar.css    - Mobile sidebar styling
- Footer.css            - Footer section styles
- HeroSection.css       - Hero/landing section
- FeaturesSection.css   - Features showcase grid

All CSS uses:
- CSS3 Media Queries for responsive design
- CSS Flexbox and Grid for layouts
- CSS Gradients for visual effects
- CSS Transitions for smooth interactions

NO Tailwind CSS - Pure custom CSS only.

======================================================================
RESPONSIVE BREAKPOINTS:
======================================================================

Mobile:  All devices < 640px
Tablet:  640px ≤ width < 1024px (md: 768px breakpoint in CSS)
Desktop: ≥ 1024px (lg: 1024px breakpoint in CSS)

Media query structure used:
- Default styling for mobile
- @media (min-width: 768px) for tablets
- @media (min-width: 1024px) for desktop

======================================================================
API CONFIGURATION:
======================================================================

API Base URL: http://localhost:8080 (configured in src/services/apiClient.ts)

Environment variable:
  VITE_API_BASE_URL=http://localhost:8080

To change API endpoint:
1. Edit src/services/apiClient.ts
2. Update the baseURL in axios.create({...})
3. Or set VITE_API_BASE_URL in .env file

======================================================================
TROUBLESHOOTING:
======================================================================

Port 5173 already in use?
  - Vite will automatically try the next available port
  - Check http://localhost:5174 if 5173 is taken

Build errors?
  - Delete node_modules folder
  - Delete package-lock.json
  - Run: npm install
  - Run: npm run build

Style not loading?
  - Clear browser cache (Ctrl+Shift+Delete)
  - Hard refresh (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac)
  - Check that CSS file exists in component folder
